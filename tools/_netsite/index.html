操作说明

  • 滚轮 缩放 · 拖拽 平移 · 双击空白 复位
  • 单指拖动 平移 · 双指捏合 缩放 · 双击空白 复位
  • 点卡片 → 聚焦这个人，只留下关系最密切的几个人
  • 聚焦状态下 再点一次卡片（或点「人物详情」）→ 打开人物档案
  • 拖动卡片 → 换到别的格子（会记住，别人加角色也不会挤走它）
  • 双击卡片 → 把这一张复位到自动位置 · ⤾ → 一键复位全部手工排版 · ↶ 或 Ctrl+Z → 撤销上一次拖动
  • ESC 或左上角 ◀ 返回上一级
  • 左上角 ◀ 返回上一级
  • 右上角切换 按团 / 按创作者 / 按类型 三种分组视角
