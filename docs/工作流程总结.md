# 🐳 工作流程总结 · TRPG-Universe Agent

> **一句话**：把「一堆 6 小时级的跑团录音 / 聊天导出」变成「可检索、可浏览、可发布的人物关系宇宙」。
>
> 本文是**流程主线**（做什么、按什么顺序）。踩坑与实现细节见 `docs/` 下的各篇交付说明。

---

## 一、整体形态：三层，别混

| 层 | 产物 | 读者 | 纪律 |
|---|---|---|---|
| **数据层** | `<工作区>\数据\characters.json` / `relations.json` | 工具与查证 | 写前备份 · `confirmed:false` 不写盘 · 生产库闸门 |
| **文本层** | `<工作区>\产出\<团>_剧情编年史.md` | 内部查证 | **带时间戳与存疑标记**，可以脏 |
| **成品层** | `site\`（关系网站 / 绘本 / CG） | 给人看 | **必须清洗**：删时间戳、元说明、编者注 |

> ⚠️ **最常见的错误**：把编年史直接端给读者。编年史是「证据」，成品是「作品」。

**单工作区多团**：所有团共用一个生产库，靠 `characters[].groups` 区分。

---

## 二、九步主链

```
① ingest  → ② transcribe → ③ segment → ④ extract → ⑤ review
                                          ↓
        ⑨ housekeep ← ⑧ export ← ⑦ visualize ← ⑥ store(chronicle 在旁边)
```

| 步 | 命令 | 产出 | 要点 |
|---|---|---|---|
| ① **ingest** | `-m trpg_agent ingest` | `manifest.json` | 素材丢进 `<工作区>\素材\<团名>\`，登记 |
| ② **transcribe** | `-m trpg_agent transcribe --group "X" --job-id N` | `素材\<团>_转写.txt` | **最耗时**（large-v3/CUDA ≈ 0.2× 音频时长）；断点续跑 = 同配置重跑 |
| ③ **segment** | `-m trpg_agent segment --group "X"` | `.trpg/segments/<团>_段N.md` | 一场 = 一段；人工段放 `素材\segments`（与派生段隔离） |
| ④ **extract** | `tools\extract_all.py [--dry-run]` | `.trpg/patches/<团>_patch.json` | LLM 只抽**角色骨架**；关系要另补（见 §四） |
| ⑤ **review** | `tools\_clip_quiz.py --group "X"` | `产出\<团>_疑问核对.html` | **别只贴文字**——把疑问处的录音**剪出来**让人听 |
| ⑥ **store** | `-m trpg_agent store --apply --allow-production` | 回填生产库 | 影子库预演 → 生产库；**只能加不能删** |
| ⑥b **chronicle** | `tools\_chronicle.py --group "X"` | `产出\<团>_剧情编年史.md` | 逐段时间线详录，**保留时间戳**（后续对齐全靠它） |
| ⑦ **visualize** | `-m trpg_agent visualize --group "X"` | `产出\<团>_关系图.html` + `_关系网.md` | **立绘登记后必须重出** |
| ⑧ **export** | `-m trpg_agent export` | `产出\astrbot知识库导入\*.md` | KB 包 |
| ⑨ **housekeep** | `-m trpg_agent housekeep` | `产出\收尾清单.md` | 汇总数据量/状态/待确认 |

## 三、断点、闸门与回滚（三条铁律）

1. **断点续跑**：同团同配置再跑 `transcribe` 即自动续跑（先截断产物到该批起点）。
   **前提：`config.yaml` 的 `asr.*` 一个字都不能改**（全进断点指纹）。
2. **生产库闸门**：`store --apply` 对生产库默认**拒绝**，需 `--allow-production`。
   写前自动备份 `<数据>\*.bak_store_<时间戳>`（留 10 份）。
3. **影子库预演**：把 `数据\` + `.trpg\{canon,patches,state,extracts}` + `manifest.json`
   复制到 `<工作区>\.trpg\shadow_ws`，`store --apply --ws "<shadow>"`——
   root ≠ production_root，闸门自动放行，**生产库零风险看成品**。

## 四、关系数据的三条补充线（`extract` 之外）

`extract` 抽关系的口径**天然偏小**（只落「师徒/配对」那类），必须补：

```
补关系：tools\_extract_relations.py --group "X"  →  tools\_merge_relations.py --group "X" --write
        →  影子库 store 预演  →  生产库 store  →  visualize
```

| 线 | 工具 | 说明 |
|---|---|---|
| **抽关系** | `_extract_relations.py` | 有编年史用编年史，否则退化为 `characters.json` 的 `events[]`；**把「当前孤立的角色」逐个喂给模型核对**——这是覆盖率关键 |
| **类型归一** | `_relation_vocab.py` | 自由写法（曾有 387 种）→ **24 个标准类型**；⚠️ **改 type 必须同时改补丁**（去重键含 type） |
| **体检** | `_relation_stats.py` | `边/节点 < 0.8` 或 `孤立角色 > 节点数/5` → 抽漏了 |
| **全库一把梭** | `_relation_fill_all.py --write` | 自动挑团 → 抽 → 并 → 预演 → 入库 → 重出图 |

## 五、视觉生产线（**先描述，再生图**）

```
角色卡/立绘/编年史 → 外貌描述（中文，带出处） → 英文锚点表 → 生图 → 挑图 → 登记
```

| 角色类型 | 口径 |
|---|---|
| **PC（玩家角色）** | **严格用角色卡内原图**（`tools\_apply_card_portraits.py`） |
| **NPC** | NAI 生成（`novelai/` 下的生图脚本，见 `novelai/NAI生图经验.md`） |
| **跨团同位体** | **复用同一张立绘**（`tools\_apply_reuse_portraits.py`） |
| **梗/明星** | 只画梗的形象，**不做真人写实脸** |

**四条硬经验**：
1. **锚点表是单一数据源**（每团一份 `novelai/` 下的 looks 锚点表脚本），CG/立绘/漫画共用。
2. **画师署名**要在**正向串末尾**加负权重 `-2::signature::, -2::watermark::, ...`——NEG 压不住。
3. **构图串别写 `simple background`**（整批变纯色底）。
4. **`BadZipFile: Bad CRC-32` ≠ 图坏了**——docx 的 zip CRC 写错时字节完好，绕过校验重读 + PIL 验证。

## 七、几条跨环节纪律

1. **批尽可能大**：单批 200–300 条，别开几十个小批（子代理初始化开销极大）。
2. **子代理不自建脚本**：读输入 → 写输出 → 回一行回执；**校验器中央化**。
3. **PowerShell 脚本一律纯英文**（Windows PowerShell 5.1 按 ANSI 代码页解析 UTF-8 脚本，中文会乱码甚至报错）；带中文的写 `tools\*.py`。
4. **清理进程按端口/PID**，不要按名字批量杀。
5. **重建 `site\` 前先停本地服务**（服务 cwd 占用 → `PermissionError: WinError 32`）。
6. **改数据三件套**：直接改 JSON + 备份 + 复验（`store` 只能加不能删）。

## 八、目录速查

```
<工作区>（例：./workspace）
├─ 素材/     原始素材（录音、聊天导出、角色卡）——⚠️ 含隐私，别外发
├─ 数据/     characters.json · relations.json · 头像/ · 关系类型受控词表.json
├─ 产出/     编年史 · 关系图 · 关系网 · 核对页 · KB 包
├─ .trpg/    patches/ canon/ state/ reports/ pickpage/（工具工作区）
└─ 归档/     过期会话文档

TRPG-agent（本仓库）
├─ trpg_agent/   主包（ingest/transcribe/segment/extract/review/store/visualize/export/housekeep）
├─ tools/        137 个可跑脚本（各脚本头部 docstring 即用法）
├─ docs/         30 篇交付说明与总结
├─ tests/        回归测试（脚本式，`python tests\test_*.py` 直接跑）
├─ examples/     脱敏示例团 `mini-group`（不依赖音频/LLM，可端到端跑通）
├─ web/ + server/    Vue3 面板 + FastAPI 薄壳
└─ site/         成品站点（构建产物，可选发布）
```
