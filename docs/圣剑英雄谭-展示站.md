> 把跑团记录做成「**一页一页翻**」的沉浸式绘本站：**133 页**剧情 + **15 张关键 CG** +
> **15 段原声** + **背景音乐** + **26 个角色档案** + 关系图，纯静态、可部署公网。

## 一、v2 改版说明（2026-10-04）

主人给了三条明确要求，本版全部落地：

### 1. UI 重做：去掉「AI 默认模板味」

旧版是三件套堆出来的（圆角卡片 + 渐变药丸按钮 + 发光阴影 + 居中堆叠），一眼假。
v2 按主人给的样板站（**明日方舟 / 重返未来:1999 / 蓝色星原**）重抽设计语言，
立成四条**反模板原则**，写进 `style.css` 顶部注释：

| 原则 | 做法 |
|---|---|
| 圆角只留给「图像」 | 界面元素一律**直角或切角**（`clip-path` 切对角，替代 `border-radius:999px`） |
| 按钮不做渐变药丸 | 描边 + **索引号（01/02/03）** + 悬停时金色从左推入填充 |
| 层级靠字重/字号/字距 | 砍掉发光与重阴影，靠对比与留白分层 |
| 非对称网格 + 大留白 | 三幕改成**横向索引长条**（序号/标题/进度），不是卡片矩阵 |

新增的「制式感」零件：
- `.brackets` **四角括号**（只画角不画框）、`.head` 章节标题（左竖条 + 中文大字 + 英文小字）
- 顶栏底部**金色游标**随当前页滑动；导航项带 `01~05` 编号
- 全局**极细噪点 + 冷光渐变**（`body::before/::after`），去掉塑料感
- 统计条做成**通栏刻度**（每格一条竖分隔线），不是六张漂浮卡

### 2. 绘本改成沉浸式放映厅

| 能力 | 实现 |
|---|---|
| **背景音乐** | `site/app.js` 的 BGM 引擎：双音轨交叉淡入 1100ms、同曲不打断；顶栏 ♪ 开关（快捷键 `M`）；状态存 `localStorage`；默认关（浏览器要求先有交互） |
| **音量闪避** | 原声（录音片段）播放时 BGM 自动压到 22%，停即恢复（`<audio>` 的 play/pause/ended 事件捕获，`capture:true`） |
| **分先后入场** | 三拍时序：**CG 先入**（0.95s 推入）→ **标题**（+0.18s）→ **正文逐句**（+0.30s 起、每句错峰 60ms）→ 元信息 +0.74s → 原声条 +0.86s |
| **翻页动画** | 框架不动、内容按行进方向错峰推进（`pushFromRight/Left`）+ **一道纸光扫过**（`.sheen`） |
| **章节动画** | 跨段/跨幕时插一张**全屏章节卡页**：竖百叶擦除入场 + 幕号 + 大标题 + 描边大页码 + "CLICK TO CONTINUE"；2.5s 自动或点击/空格跳过；卡页期间正片动画**暂停**，收场后再播 |
| **进度轨** | 顶部 2px 通栏进度 + **刻度标记**（每段一个细刻度，跨幕处加粗金色） |
| **底栏** | 上一页/下一页/目录 + 段名与时间范围 + 页码 + 键盘提示 |

快捷键：`←/→/空格` 翻页、`Home/End` 首末页、`M` 音乐、`F` 全屏、`Esc` 关灯箱/跳过卡页。

### 3. 拆页重排（顺带修掉的观感问题）

旧版 132 字/页是**贪婪累积**，末尾常留一个两三行的小尾巴页（最短页只有 3 个字），
读起来像半空的 PPT。v2 改成**按句数均分**（`split_pages`）：

```
总量 → 页数 = ceil(总字数 / 210)；每页句数 = ceil(句数 / 页数)
```

> 效果：**217 页 → 133 页**；最短页由 3 字 → **85 字**；平均 153 字。
>
> 另外：**没有 CG 的小节不再放灰色占位块**，正文直接占满整页（`.leaf.textonly`）；
> 书页高度随内容（短页不再被撑成一张空卡片），整页在舞台里垂直居中。

## 四、构建（四条命令，幂等）


## 八、内容清洗规则（`build_site.py` 的 `clean_text`）

站点的文字与"内部编年史"是**两套口径**：编年史给查证用（带时间戳、存疑标记、编者注），
站点给人读。`clean_text()` 在构建时统一洗：

1. **时间戳引用全删**：`（[4061.98-4062.98]）`、`（[3876.08]）`、`（15135-15137）`、`（约8462-8699）`、`（[7372.??]）`
2. **元说明删**：`转写里有人判断：`、`转写中他说`、`KP描述：`、`角色卡设定：`
3. **编者注删**：`（**主人确认：…**）`、`（2026-10-03 修正：…）`（括号配对删除，不误伤剧情括号）
4. **术语校正**（canon 校正表子集）：黄泳多→煌炎国、无龙茶→乌龙茶、80铁饭→80铁砧、艳术→鼹鼠人、
   死鬼→尸鬼、士兮→四骑士、贤将/铁将/敌者→铁匠、高文→高温、色蛮亚→瑟莱娅·阿尔根、
   虚空镇店/神殿→虚空圣殿、爱人国→矮人国、吉祖哥→肌肉哥、天地/天骑/天底/天气四骑士→天启四骑士、
   南斯洛特→兰斯洛特、维克多→维克托
5. **存疑标记清**：中文词后的半角 `?`（`威尔娜?` → `威尔娜`）
6. **`PC` → `众人`**：⚠️ 必须避开 `NPC`（v2 修过这个 bug：旧写法把「神秘 NPC」啃成「神秘 N众」）

> 复查：`tools\check_site.py`（14 条模式规则 + 空页 + 缺图 + 页长分布，当前 **0 残渣**）、
> `tools\_audit_text.py`（编年史口径的残留统计）、`tools\_page_index.py`（列页索引，找带 CG 的页）。

## 九、部署（2026-10-04 已上线 ✅）

**公网地址**：<https://sjt-chronicle.sjt-chronicle.workers.dev>

```powershell
npx --yes wrangler@latest deploy          # 用 wrangler.jsonc 的 assets: ./site
```

> ⚠️ URL 里 `sjt-chronicle` 出现**两次**是正常的，别以为是 bug：
> 前一段是 **worker 名**（`wrangler.jsonc` 的 `name`），后一段是**账号的 workers.dev 子域名**。
> 两者恰好同名（都是 `sjt-chronicle`），所以拼出来重复。想变短就把子域名改掉。

**踩过的两个卡点**

1. **Cloudflare 邮箱验证**：上一会话因 `Your user email must been verified [8000077]` 卡住。
   本次（2026-10-04）实测**已经不再拦**（主人邮箱大概已验证或风控放宽），可以正常部署。
2. **必须先在账号里注册 workers.dev 子域名**，否则 `wrangler deploy` 会报
   `You need to register a workers.dev subdomain before publishing to workers.dev`
   （非交互环境下它会用 fallback 值 "no"，所以脚本里永远过不去）。
   注册方式（不进面板，直接调 API；脚本：`tools\_cf_subdomain.py`）：

   ```powershell
   .\.venv\Scripts\python.exe tools\_cf_subdomain.py            # 自动注册（候选名 sjt-chronicle 等）
   .\.venv\Scripts\python.exe tools\_cf_subdomain.py --status    # 只查现状
   ```

   它等价于 `PUT /accounts/<id>/workers/subdomain {"subdomain":"..."}`。
   （附：`GET` 该 endpoint 返回 404 + code 10007 = 还没有子域名，不是路径写错。）

**⚠️ 国内网络注意**：`*.workers.dev` 在国内**直连超时**（本机实测 `curl` 直连 12s 无响应），
必须走代理才能打开（本机 Clash 在 `127.0.0.1:7897`，走它 200 / 4.4s）。
所以分享给别人时先确认对方能不能访问；若要面向国内，建议绑自定义域名。
