## 一、这一轮为什么做这个

主人拿到了一台服务器（Debian 12），要求把网站搬上去，并把「提案箱（提交→审核→覆盖层）」
改成**自由在线编辑** —— 理由很直接：*都是一起玩认识的人，不需要审核关*。

于是本轮干了两件事：
1. **自托管**：静态站 + FastAPI 后端 + 数据/版本历史，全在自己服务器上
2. **自由编辑**：专门的编辑器页面，改角色/关系/标签/团，Markdown 实时预览，带版本历史与回滚

## 三、关键设计决策（下个会话别推翻）

1. **权威数据是 JSON 文件，不是数据库表** —— 人可读、可 git、可手工改，也能被既有 `trpg_agent`
   工具链（store / build_net_site / _pull_suggestions）直接读。角色字段还在演进，表结构太僵。
2. **SQLite 只存版本历史** —— 每次保存一份 gzip 全量快照。236 角色 JSON ≈ 300KB，gzip 后约 40–60KB，
   存上千版也就几十 MB，换来「谁改了什么 + 一键回滚」。
3. **站点与编辑器用两套口径**（`scope=site` / `scope=all`）—— 见主交接「必须先知道的四件事 ①」。
4. **写进去就是真的**（无审核），安全靠三件套：共享口令 + 版本历史 + 危险操作自动备份。
5. **编辑器不侵入 app.js** —— 靠事件代理 + `window.__editorOpen` 接入，app.js 只管画图。

## 四、踩坑全集（按疼的程度排）

1. **`/api/data` 忘了「选角」** → 站点角色数从 135 跳到 266 → **卡片网重叠错位**
   （布局参数按 135 调的）。修：把建站脚本的选角逻辑搬进服务器。
2. **`avatar` 直接吐生产库的 Windows 路径**（`数据\头像\xxx.jpg`）→ **全部 404 破图**。
   修：按文件名去 `assets/portraits/` 找 `<id>_t.jpg`/`<id>_f.jpg`；找不到返回 `null`
   （前端显示「未解封」剪影卡，比破图体面）。
3. **pip 的两个坑**：只给 `-i` 仍会从 `files.pythonhosted.org` 拉而 `ReadTimeout`；
   镜像环境变量**必须设在 `pip install --upgrade pip` 之前**，否则那步先超时、`set -e` 直接带走脚本。
4. **`uvicorn[standard]` 别装**（httptools/uvloop 等 C 扩展在小机器上编译慢/失败）。
5. **`server/data/` 要给 `www-data` 可写**，否则「能读不能写、保存 500」。
6. **重建 `site\` 前要停掉所有占用者** —— 不只 `8899` 的 http.server，**还有 `wrangler dev`**；
   否则 `rmtree` 失败、`site\` 被删空、**残版推上线**（本轮真发生过，4 个前端文件 404）。
   ⚠️ 且**部署后别立刻验证**，CDN 有传播延迟，会误判成失败。
7. **`editor.js` 是动态加载的**（wiki-boot → app → wiki → editor）：
   - 事件绑定**不能**写在 `document.addEventListener('DOMContentLoaded', …)` 里 → **永不执行**，
     表现是「点了保存毫无反应、日志里连一条 POST 都没有」（查了很久）
   - 它比 `wiki.js` **晚加载**，`wiki.js` 跑首屏路由时 `window.__editorOpen` 还不存在 →
     `#/edit` 被静默跳过。修：editor.js 加载完自己检查 hash 补开
8. **面板类 UI 必须断言「可见性」**，不能只断言「元素存在」—— 本轮两次被骗：
   审核页盖住档案页、首页盖住深链角色页。断言方式：元素中心点 `elementFromPoint` 必须命中自身。
9. **PowerShell + SSH 的引号地狱**：复杂命令（`awk`/嵌套引号/heredoc）**写文件传上去再 bash**；
   组合命令容易整体卡死（本轮 600s 超时一次）→ **一次只做一件事**；探活一律**短超时**。
10. **`ssh-keygen -N ""` 在 PowerShell 里参数被吃**（一直吐 usage）→ 密钥没配成，现在靠密码。
    要配就用 **cmd** 跑。
