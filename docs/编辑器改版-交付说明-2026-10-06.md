## 二、过程中抓到并修掉的三个真 bug

1. **`#/edit/<id>` 会被抹成 `#/edit`** —— `wiki.js` 的 `curHash()` 写死了 `'#/edit'`，任何一次 `syncHash()`（切视图/关面板）都会把角色 id 冲掉，表现是"跳进去了，但地址栏丢了角色、刷新只剩空编辑器"。
   修法：`curHash()` 调 `window.__editorId()` 带上当前编辑的 id。
2. **测试点选位置导致的假失败** —— 用 `elementFromPoint` 取编辑器左上角时命中的是标题栏 `h3`，于是误判"被档案页盖住"。改成取**卡片内容区中点**再向上找 `#editor`，才是真断言（编辑器 `z-index:170` > 档案页 `60`）。
3. **门户页的 `innerHTML` 会吃掉自己**（上一轮）：`loadNew()` / `loadAnn()` 原来往 `#pvNew` / `#pvAnn` 整体写 `innerHTML`，把同容器里的表单一起清了 —— 改成只写子容器 `#pnFeed` / `#pnAnn`。

## 四、部署（要推的是前端）

改动全在 `tools/_netsite/`（构建产物 `site/`），服务端没动。所以只推前端：

```powershell
scp -r <仓库>\site\* root@<服务器IP>:/opt/trpg-wiki/site/
```

**如果上一轮的数据没推**（线上还是 266 人），顺手把这两条也跑了：

```powershell
scp <仓库>\.tmp\to_upload\characters.json <仓库>\.tmp\to_upload\relations.json root@<服务器IP>:/opt/trpg-wiki/server/data/
ssh root@<服务器IP> "chown www-data:www-data /opt/trpg-wiki/server/data/*.json && systemctl restart trpg-wiki"
```

推完**硬刷新**（`Ctrl+F5`），然后看这四点：
1. 打开任意角色 → 操作条只有「✎ 编辑这个角色」「☰ 门户」；
2. 点编辑 → 左边是立绘（没图的显示占位），右边是表单；
3. 点「🖼 上传 / 更换立绘」选张图 → 左边立刻出图；
4. 窄屏（手机）下两栏自动变成上下。
