> 2026-10-04 首个小样。目标：验证「把跑团记录画成漫画」这条管线是否成立。
> 入口：<http://127.0.0.1:8899/site/comic.html>（线上 `/comic.html`，首页第 4 个按钮「分格漫画」）

## 一、版式：抄的是日式 replay，不是美漫

日式 TRPG **リプレイ本**的核心不是"画得多好"，而是**两层同页对照**：

| 层 | 我们怎么落 | 作用 |
|---|---|---|
| **演出层** | 分格底图 + **旁白框** + **对话框**（带尾巴） | 读起来像漫画/轻小说，给"成品" |
| **桌边层** | 每节末尾「**桌边原声**」框：贴原始转写片段 + 播放器 | 给"这桌实际怎么跑的"——replay 的味道所在 |

配套的印刷物暗示：纸色底（`#efe9dc`）+ 深墨字、格子墨框、竖排英文书脊、格号 `PANEL 01`、
格下编者小字、页码与「下一节」提示。

## 二、关键技术决策（都踩过）

### 1. 对话框**不画在图里**

AI 画中文字必崩（NovelAI 的英文都可能糊，中文更差）。所以：

- 底图**只出画面**，NEG 里加 `speech bubble, dialogue box, caption text, text, letters`，
  正向串末尾加 `no text`；
- 对话框、旁白框由 **HTML/CSS 叠加**（`.say` / `.nar`）。

好处：**可改、可搜、可选中、可多语言**，改台词不用重出图。

### 2. 台词**照抄编年史原文**

`tools/build_comic.py` 的 `EPISODES` 里，`nar`（旁白）与 `line`（台词）逐条取自
`产出\圣剑英雄谭_剧情编年史.md` 该节正文，**不编造**。原文里的口语与 ASR 错字（如
「大地址的剑术」「把他吸二手一眼」）**保留**——这正是 replay 的质感，改clean了反而没味。

### 3. 多角色同框：PC 走角色栏，NPC 写主串

沿用 PC 版 CG 的教训（见 `docs\PL角色外貌设定.md` §十）：

- PC（八重樱/飒飒米…）只写进 **Character 栏**，主串不重复描述 → 否则同一人被画成两个；
- NPC（威尔娜没有卡内立绘以外的锚点表）在**主串**里写清外貌（棕双辫、皮甲、短斗篷）。

### 4. 漫画风尾

底图统一追加：

```
monochrome ink lineart with flat cel shading, manga panel art, clean outlines,
screentone shading, dramatic composition, anime illustration
```

实测出来是"单色墨线 + 网点"的彩页感，与既有 CG 的水彩/厚涂风区分开，适合分格。

## 四、工具

```powershell

python <NAI库>\trpg-gen23-comic.py

# 2) 生成漫画页（读 archive/23-trpg-comic，转 jpg 到 site/assets/comic）
```

  改文案不用碰 JS。

## 五、试样的结论：管线成立，但有三个已知问题

### ✅ 成立的部分
- 版式立住了：纸色页 + 墨框格 + 两框（旁白/对话）+ 桌边原声，读起来确实"像书"；
- 关键道具与识别点都在：烟管、酒葫芦、长刀（八重樱）；双辫、皮甲（威尔娜）；
- 无 AI 水印、无署名（`SIG_KILL` 生效）、无文字乱码（因为文字不是 AI 画的）。

### ⚠️ 待解决
1. **构图不稳**：格 03 第一版塞了三人 + 乐器 + 闪电，糊成一团；改成单人特写才干净。
   → **结论：每格 ≤2 人，动作场景尽量单人**，靠分镜而不是靠"一格里塞满"。
2. **连续性**：三格之间靠角色栏锚点维持一致性，但**服装细节仍会漂**。
   若要更稳，需要给每格加 `seed` 约束或引入参考图（V5 的 reference 支持未确认，见 skill §1.2）。
3. **身体比例偏漫画化**：格 03 的腰臀比夸张。
   → 可在角色栏加体型词（如 `slim waist`）或换 seed；属于"抽卡"问题，不是管线问题。

## 六、如果要铺到全部 78 节

**成本估算**

| 项 | 量 | 说明 |
|---|---|---|
| 分镜文字 | 78 节 × 3~4 格 | 需 LLM 把每节正文改写成分镜表（谁/动作/表情/镜头/台词/旁白） |
| 底图 | ≈ 250~300 张 | 免费档每张 ~9 秒 → **40~45 分钟**（分批跑，注意别打满内存） |
| 页面 | 1 套模板 | `build_comic.py` 已可复用，加数据即可 |

**工序**：正文 → 分镜表（LLM）→ 人工过一遍台词（**避免编造**）→ 出图 → 生成页。

**建议的推进方式**：先做**一整段（段1，10 节 ≈ 35 格）**当第一章，
看整体节奏对不对，再决定要不要全铺。逐段交付比一次性全做完更安全。

### ⚠️ 内存警告（踩过）
批量出图时 Edge/浏览器子进程会堆内存（本项目实测堆到 26 个 / 3.3GB，
把 15.7GB 机器压到 0GB 可用，之后连 `Get-Process` 都超时）。
**分批跑、跑完清进程**，别一次开几十个。
